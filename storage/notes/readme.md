## About This Workspace

This workspace lives at `storage/notes` inside the mdtree application. It is a plain folder of Markdown files — no database, no sync service. Edit files in any text editor and mdtree will reflect the changes on next load.

## Tips

- Use the sidebar to browse folders and files
- Click any `.md` file to open it
- Use the workspace switcher (top of sidebar) to jump between workspaces
- The URL updates as you navigate — bookmark any file's URL to return directly
