# Keyboard Shortcuts

> See also: [Markdown tips](markdown-tips.md) — [Back to root](../readme.md)

## mdtree (Planned)

These shortcuts are planned for the v2 editor release.

| Shortcut | Action |
|---|---|
| `Cmd/Ctrl + S` | Save current file |
| `Cmd/Ctrl + P` | Quick file open (fuzzy search) |
| `Cmd/Ctrl + B` | Toggle sidebar |
| `Cmd/Ctrl + Shift + F` | Search across all files |
| `Cmd/Ctrl + N` | New file |
| `Escape` | Close modal / deselect |

## TipTap Editor (v2)

| Shortcut | Action |
|---|---|
| `Cmd/Ctrl + B` | **Bold** |
| `Cmd/Ctrl + I` | *Italic* |
| `Cmd/Ctrl + K` | Insert link |
| `Cmd/Ctrl + Z` | Undo |
| `Cmd/Ctrl + Shift + Z` | Redo |
| `Cmd/Ctrl + Alt + 1` | Heading 1 |
| `Cmd/Ctrl + Alt + 2` | Heading 2 |
| `Cmd/Ctrl + Alt + C` | Code block |
| `Tab` | Indent list item |
| `Shift + Tab` | Dedent list item |

## Browser

| Shortcut | Action |
|---|---|
| `Alt + Left` | Navigate back |
| `Alt + Right` | Navigate forward |
| `Cmd/Ctrl + L` | Focus address bar (bookmark a note URL) |
| `Cmd/Ctrl + D` | Bookmark current note |
